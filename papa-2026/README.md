# papa-2026 ⚽🎂

Web de cumpleaños para papá (12 de noviembre) — edición fútbol argentino.

- **Sellada hasta el 12 de noviembre**: antes de esa fecha se ve la pantalla de espera, con la pelota sellada, la cuenta regresiva y una tanda de penales para matar la espera.
- **El día del cumple**: estadio de noche, videomarcador LED, torta albiceleste con velitas soplables, figuritas estilo Panini, serpentinas, fuegos artificiales al tocar el cielo, música de cajita, pelotitas atrapables y una carta de hijo a padre.
- El deseo que escriba después de soplar las velas se enciende en el videomarcador del estadio.
- **La búsqueda del tesoro del capitán 🗺️**: 6 pistas en verso por toda la casa (cocina → salón → pasillo → cuarto de Leo → cuarto de los padres → el armario de mi habitación), con caminos falsos al baño que sacan tarjeta amarilla 🟨 con bromas. El progreso se guarda solo (`localStorage`).

## Enlaces

- Web: https://giocavallic-lgtm.github.io/birthday-apps/papa-2026/
- Para verla antes del día: añade `?preview` a la URL (no compartir).

## Desarrollo

```bash
npm install
npm run dev
```

Build: `npm run build` → subir el contenido de `dist/` a la rama `gh-pages`, dentro de la carpeta `papa-2026/`.
